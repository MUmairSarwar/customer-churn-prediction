# Dataset

`telco_customer_churn.csv` is the **Telco Customer Churn** sample published in IBM's `telco-customer-churn-on-icp4d` repository. It contains 7,043 customer rows and 21 columns describing demographics, services, billing, contracts and churn.

Source: https://github.com/IBM/telco-customer-churn-on-icp4d/tree/master/data

The dataset is used here for portfolio and educational analysis. It is a public sample, not current production data, and its customer identifiers are synthetic.
